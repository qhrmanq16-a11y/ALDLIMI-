# ALDLIMI

هذا المستودع يحتوي على قالب موقع Landing Page أساسي باستخدام Next.js و Tailwind CSS، مصمم لتجربة سريعة واحترافية للمنصة ALDLIMI.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح المتصفح على:

```bash
http://localhost:3000
```

## البناء للإنتاج

```bash
npm run build
npm run start
```

## المكونات الأساسية
- Navbar
- Hero Section
- Features Grid
- Footer
- تصميم متجاوب وقابل للوصول
